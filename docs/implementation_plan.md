# プロジェクト構造の大規模整理（Web / Android / 共通）

## 目的
ユーザーの要望に基づき、現在の単一プロジェクトを「Webアプリ」「Androidアプリ」「共通機能」に明確に分割し、今後の開発・管理をスケールしやすくします。
また、これまで作成した `implementation_plan.md` などの重要な設計ドキュメントを、プロジェクトフォルダ内に永続的に保存します。

---

## Proposed Changes (変更内容)

### 1. ドキュメントの保存先作成
プロジェクト直下に `docs/` フォルダを新設し、これまでの要件定義やアーキテクチャ設計などの計画ドキュメントをMarkdownファイルとして保存します。

### 2. フォルダ構造の分割
全体を以下の3つの主要なフォルダに分割します。（技術的には「npm workspaces」などを活用し、フォルダ間でコードを共有できるモノレポ構成を想定します）

#### 📁 `common/` (共通フォルダ)
- **役割**: WebとAndroidの両方で使われる「定数」や「計算ロジック」を配置します。
- **内容例**: 
  - `constants.js` (目標体重 75kg、期間92日、開始日などの設定)
  - `calculations.js` (消費カロリーや理論上の減量幅を計算する関数)

#### 📁 `web_app/`
- **役割**: PCや大画面タブレットでの閲覧を前提とした、全体俯瞰用のWebダッシュボード。
- **内容例**: これまでのVite + Reactプロジェクトのベースをこちらに移動します。

#### 📁 `android_app/`
- **役割**: 毎日持ち歩いてカロリーを記録するための、モバイル特化型アプリ。
- **内容例**: 先ほど実装したスマホ向けのUI（ボトムナビ、リング表示、ワンタップ記録ボタンなど）をこちらに配置します。
