# ダイエット要件・ルールブック (Diet Rules)

このドキュメントは、本プロジェクトにおける「ダイエットの目標」および「食事・運動のルール」を一元管理するための恒久的な仕様書です。

## 🎯 目標設定 (The Goal)
* **開始日**: 2026年6月17日
* **開始体重**: 86.0 kg
* **目標体重**: 75.0 kg
* **期間**: 3ヶ月（92日間）
* **全体減量目標**: 11.0 kg

---

## 🍽️ 食事ルール (Diet Plan)

曜日と時間帯に応じて、あらかじめ設定されたカロリー目標があります。

* **朝**: 月〜金は 1000kcal（固定のルーティン）
* **昼**: 自由入力（デフォルト値なし）
* **夜**:
  * **月曜・木曜**: 600kcal を基準とする
  * **それ以外の曜日**: 300kcal を基準とする

---

## 🏃 運動ルール (Exercise Plan)

一週間を単位（月曜始まり〜日曜終わり）として、合計 **800kcal** の運動消費を目標とします。

* **固定の運動日**:
  * 月曜日: 100kcal の消費
  * 木曜日: 100kcal の消費
* **任意の運動日**:
  * それ以外の曜日で「2日間」、それぞれ 300kcal ずつ消費する（計600kcal）
* **週次合計目標**: 100 + 100 + 300 + 300 = **800kcal / 週**

### プリセット運動（実績入力ボタン用）
アプリ上では、以下のボタンからワンタップで運動実績を記録します。
* 🏃 ランニング (1km) : 100 kcal
* 🏃 ランニング (3km) : 260 kcal
* 🤸 体操・ワークアウト : 100 kcal
* ⚽ サッカー : 300 kcal

---

## 📊 理論上の減量幅の計算式
* **消費カロリーの原則**: 脂肪1kgを減らすためには、約 **7200kcal** の赤字が必要です。
* **1日の基礎代謝等（消費）** - **(食事摂取カロリー - 運動消費カロリー)** = 1日のカロリー赤字
* **理論減量幅(kg)** = 累積カロリー赤字 ÷ 7200
