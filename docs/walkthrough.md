# 🎉 実装完了ウォークスルー (v2.0 & v2.1)

これまでに実装された主要な機能とアーキテクチャの大幅な進化についてまとめました。

---

## 📱 1. Androidネイティブアプリ化 (Capacitor導入)
「スマホ画面サイズのWebサイト」から、**「本物のAndroidアプリ（.apk）」**としてビルド・インストール可能な構成へと進化しました。

* **Capacitorの導入**: `android_app` フォルダ内に `android/` プロジェクトが生成されました。
* **ビルドの仕組み**: 今後WebUI（React）を修正した際は、`npm run build` と `npx cap sync` を実行するだけで、最新の画面がAndroid側のコードに自動連携されます。
* **インストール**: [Androidビルド手順.md](docs/Androidビルド手順.md) に沿ってビルドしたAPKファイルをスマホに送ることで、ネイティブアプリとしてインストール可能です。

---

## 🤸 2. 運動（消費カロリー）記録機能と週次目標トラッキング
毎日の運動によるカロリー消費を記録し、1週間の目標達成度を図る機能を実装しました。

* **UIの追加**: 「食事記録タブ」の下部に、新しく **「運動記録セクション」** を追加しました。
* **クイック記録ボタン**: 
  - 🏃 ランニング 1km (+100kcal)
  - 🏃 ランニング 3km (+260kcal)
  - 🤸 体操 (+100kcal)
  - ⚽ サッカー (+300kcal)
  ワンタップでその日の消費カロリーに加算されます。手入力での自由な上書きも可能です。
* **週次プログレスバー**:
  - 月曜日を起点として日曜日までの運動量を自動で集計します。
  - **「週の目標: 800kcal」** に対して現在何kcal消費したかが、リアルタイムで伸びるプログレスバーで視覚化されます。目標（800kcal）に到達するとバーが緑色に光ります。

---

## 🍽️ 3. 曜日別の食事（夜）カロリーサジェスト
ルールブックに定義された目標に基づき、入力の手間を極限まで省く仕組みを導入しました。

* **月曜日と木曜日**:
  - 「夜（Evening）」のデフォルト入力ボタンが自動的に **「月・木基準 600kcal」** に切り替わります。
* **火・水・金・土・日**:
  - デフォルト入力ボタンが **「基本基準 300kcal」** に切り替わります。
* **理論減量幅への還元**:
  - 記録された食事カロリーと運動カロリーは瞬時に相殺・計算され、「理論上の減量幅（1kg=7200kcal換算）」に反映されます。
